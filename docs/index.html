00Resumen

El repositorio contiene una sola aplicación real: el sitio PHP de la raíz. html/ es un export estático derivado y maquetas/ es referencia de diseño; ninguno de los dos reemplaza al sitio dinámico.

Raíz del proyecto18 archivos · Entrada PHP, configuración central, esquema SQL, lanzador y documentación.
admin/ — Panel de administración14 archivos · 14 archivos. Acceso con login + CSRF, ABM, pedidos, importador y respaldos protegidos.
api/ — Endpoints JSON2 archivos · Dos endpoints: catálogo público (GET) y creación de pedidos (POST).
assets/ — Estilos y librerías6 archivos · CSS/JS compartidos por la app PHP. Incluye Bootstrap y jQuery versionados localmente.
partials/ — Piezas compartidas3 archivos · Header, footer y carrito global: se incluyen desde casi todas las páginas PHP.
img/ — Imágenes de la app PHP80 archivos · Catálogo, fuentes para importar, promociones, logo, favicon y Open Graph.
html/ — Export estático89 archivos · 89 archivos. Sitio HTML puro sin PHP ni BD; disponible en http://localhost/Marea_celestial/html/.
maquetas/ — Diseño original6 archivos · 6 archivos. Maquetas HTML de referencia visual; NO se sirven desde Apache.
docs/ — Documentación3 archivos · 1 archivo HTML autocontenido con el mapa técnico del repositorio.
Regla rápida: para el sitio en producción se usa la raíz PHP + img/ + assets/ + partials/ + api/. html/ se publica tal cual solo en el modo estático. maquetas/ no se sirve.

12Reglas de mantenimiento

No subir secretos: .env está ignorado por Git y bloqueado por Apache. Versionar solo .env.example.
No tocar: admin/_backups/.htaccess (protege los respaldos), la transacción y el doble control de stock en api/pedido.php, ni el orden de carga de los CSS en partials/header.php.
Vendor: Bootstrap y jQuery están duplicados en assets/ y html/assets/. Son librerías minificadas: no editarlas a mano.
catalogo.sql: al importarlo se ejecutan DROP TABLE IF EXISTS. Es solo para inicializar; reimportarlo sobre datos reales los borra.
Pendiente fuera de este mapa: ajustes medios/bajos relevados en admin/ (flash de errores del importador, separador con ;, matching fuzzy de categorías, colisión de nombres de backup, entre otros).
