# Maquetas de diseño

Aquí viven las versiones HTML originales del diseño del sitio:

- `index-mejorado.html`
- `productos-mejorado.html`
- `colecciones-mejorado.html`
- `sobre-nosotros-mejorado.html`
- `contacto-mejorado.html`

**No se sirven desde Apache.** El sitio real son los archivos PHP de la raíz. Estas maquetas se conservan solo como referencia visual/fuente de diseño.

Las imágenes se referencian con `../img/...` porque esta carpeta está un nivel por debajo de la raíz.
